Try a model

Send a real message to a real model and see what comes back. Pick a key and a model, type something, then press Generate. This spends tokens on your account, the same as using the provider directly.

Optional extras, tick one to reveal its settings. Support varies by model as well as by provider, so if one is refused the reply says which model turned it down and you can pick another.

Show the model a picture

Choose a picture from this computer, or paste a link to one, and the model will look at it and answer questions about it. Try asking "what is in this picture?"

This does not make new pictures. KeyCall only sends pictures to a model and reads its written reply, so a request like "generate an image of a rabbit" comes back as words, not a picture.

Not every provider takes pictures. If yours doesn't, the reply will say so and tell you what it does accept.

Give the model a tool to call

A tool is something the model can ask you to do for it, like looking up the weather. The model never runs it. It asks, you type the answer, and the conversation carries on with your answer. Press "Load example" to see a working one.

Check every key at once

Tests all of your keys in one go and shows what each one can actually do. A key can look fine and still fail in practice, because providers list models that they then refuse to run. Verify tries them in order and reports every attempt, so you can see exactly where a key stands.

Leave the box below unticked to check the keys only. Tick it to also send one short message per key, which proves the key can generate text. That costs a small number of tokens on each account.
