Add an API key to get started

Paste a key from any supported provider. It goes to the KeyCall process running on your own machine, is held in memory for as long as that process runs, and is never written to disk. Closing KeyCall forgets it.

Check every key at once

Tests all of your keys in one go and shows what each one can do. A key can look fine and still fail in practice, because providers list models that they then refuse to run. Verify tries them in order and reports every attempt, so you can see where a key stands.

Leave the box below unticked to check the keys only. Tick it to also send one short message per key, which proves the key can generate text. That costs a small number of tokens on each account.
